# 采集器改进与延期在线验收

日期：2026-10-29（Asia/Tokyo）。本记录只说明代码实现和离线验证，不声明新版在线更快或成功率更高。

## 当前批次保护

开发前只读确认 WSL 中已有独立 Python 采集进程，参数为原生浏览器、单 worker、2 秒间隔。开发期间没有向该进程发信号、重启、注入新配置或写入其原始采集目录。它已经加载的 Python 模块不会因源码编辑而热更新。本次没有启动新版在线采集、在线对照或监控任务。

## 已实现

- `Retry-After` 不区分头名称大小写，支持秒数及 HTTP 日期；不把服务器等待缩短为 30 秒。最后一次请求的等待约束同样作用于后续实体，403 提供该响应头时也遵守。
- 同一主机使用共享请求调度器。连续拒绝或失败后默认最多两次冷却恢复，每次至少 120 秒；单次探测失败立即再次熔断，成功不会重置恢复次数。交互验证码停止自动恢复。
- 待处理 future 数量不超过 worker 数；新响应解析结果在内存中传递，不再读回正文后重复解析。浏览器请求与另一个 worker 的解析、写盘可重叠，仍受全局速率约束。
- 可选 `browser-fetch` 使用同一浏览器会话的同源请求，保留完整响应字节；校验或读取失败最多回退一次原生导航，普通拒绝交给主机调度器。
- 可选 `light` 资源模式仅阻断图片、字体和媒体，保留文档、脚本、样式与校验请求。默认关闭；路由禁用 HTTP 缓存的代价须在线比较。
- 记录实际浏览器版本、UA、品牌版本、平台及语言等一致性信息，不修改浏览器暴露属性、不声称不可识别。仅在浏览器实际断开或页面关闭后重建浏览器，不通过拒绝响应轮换身份。
- 新增一次性 `compare` 命令：原批次未完整结束、归档发布未完成或仍有采集/对照进程时，在联网前拒绝启动。最新 Wago 版本在试验前后必须保持一致。

## 离线验证

- Windows Python 3.12：63 项测试通过，包含 Lua 5.1 路径；测试进程的网络连接被禁用。
- Linux Python 3.14：63 项测试通过，在独立临时源码目录执行；测试进程的网络连接被禁用。
- 14 项新增测试覆盖等待时间、有限恢复、验证码停止、完整字节、导航回退、资源类型、浏览器重建、一致性诊断、有界任务及只解析一次、对照门禁、样本稳定性和对照失败证据。

## 本批结束后运行

在配置好现有锁定依赖和浏览器的 Linux 环境中执行：

```sh
python -m data_pipeline.professions compare \
  --after-raw .pipeline-runtime/prof-learning-full-20261029 \
  --out dist/prof-learning/transport-comparison-20261029 \
  --limit 12 --rounds 2 --interval 2
```

输出必须为全新目录。命令不等待、不监控当前批次，未满足门禁则退出。

样本按实体类型与来源状态分层选取，包括失败来源；同样本、同间隔、同解析器分别比较原生导航、同会话轻量读取、资源裁剪，两轮交换执行顺序，每组重复冷、热两遍。遇到拒绝或连接错误保存证据后停止整场对照。

报告包含有效资料/分钟、验证通过率、受阻率、耗时、页面目标 CDP 请求数、传输字节、缓存命中，以及逐实体事实和状态差异。CDP 字节不包含其他目标和协议开销，不能冒充系统总流量。未观察真实 202 校验时明确标记，不能宣称该项实测通过。

这是传输模式对照，不是旧、新整个流水线的端到端基准。线上效果、真实校验兼容性和默认模式是否需要调整仍待此次对照。所有试验产物标记 `generationInput=false`，不会替换正式学习 Data。
