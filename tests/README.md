购物清单不扣已有物品，逐项标明 NPC 购买或拍卖行；NPC 物品不导入 Auctionator。NPC 使用插件内置的已核验整包金额和购买数量；没有可靠内置价则自动最省钱路线改用本专业制材或放弃相关冲级候选，不使用 AH 价代替。固定攻略仍可显示缺价材料。只有点击实际制作按钮时检查背包。含旧 NPC 报价的方案需手动“重新计算”应用新策略；AH-only 路线和冻结执行记录继续保留。

后台自动执行材料成本搜索并显示已比较状态数与实际节省金额；已删除“继续优化”入口。计算完成或达到本轮预算后保留最好结果，未证明最优时明确说明；修改输入后用“重新计算”。

另一主专业的制材自动参与比较；主动提高另一专业等级需要开启“允许联合升级另一主专业”。有冷却的制作不参与。NPC 材料只使用内置已核验、不限量、纯金币、角色可购买的供应；不读写玩家商人价格，也不使用 Auctionator 商人价。不同 NPC 资料价可能含不同折扣，不自动推算声望折扣；召唤 NPC 需要明确可访问证据。

查看未学专业且开启联合升级时，升级页要求主动选择搭配的主专业，没有默认选择；可以选已学或未学专业。路线只使用目标和该搭配，其他原有主专业不参与。已学搭配使用实际技能，未学搭配从 1 开始；未学目标关闭联合升级时只计算目标专业。搭配按角色、服务器和目标专业保存，更改后点击“重新计算”。未选择或旧路线配对不符时，路线、购物清单、HUD 和导入均等待选择或重算。仅首次没有任何方案时，选择完成后可自动开始计算。

## 游戏内验收

离线结果不能替代以下实机检查：

1. 未学专业直接显示参考材料；打开已学专业，用 `/dfprofapi` 确认接口能力与读取情况。打开商人前后价格应始终来自内置资料，不新增玩家价格记录。改变背包/银行库存不应改变材料报价，学费与工具不应进入清单。详见 [FOREVER_API.md](FOREVER_API.md)。
2. 铜/锡/青铜等熔炼产量以当前客户端为准；灰色熔炼只制材，140–155 与 185–300 检查点按真实采矿技能推进。
3. 排除中间材料配方后，高级配方改用购买或其他未禁用配方；无法满足时明确受阻，不自动解除限制。
4. 做一段制材/联合升级，核对 HUD 的执行顺序及材料依赖，产物被消耗后不计出售收入。
5. 价格更新、学习配方、改变目标、停止/重算、重载后的规则恢复，以及游戏中的帧时间和内存表现。
6. 两个主专业已学时，查看第三个未学专业并开启联合升级：必须先选搭配，不能同时出现三个专业。分别选已学/未学搭配，核对技能起点、路线与购物清单；更换搭配后旧步骤应收起。开启“仅使用已学习的配方”仍能预览未学专业，但已学搭配继续受此限制。
7. 在固定攻略及各自动模式检查所需图纸、一次性费用及来源地图。核对内置报价与固定/限量/未知标签，访问商人不改变报价或写入现货；仅任务来源且无 AH 报价的未学配方应被自动路线替代。已学后重算免除图纸，NPC 图纸不能导入 AH。
8. 在拍卖师处完整扫描、单物品搜索并购买一次，核对材料/图纸的数量、来源、观测时间、本人排除与购买后更新；用 `/dfauction` 检查监听。数量不足时选其他配方补齐，材料与图纸共用上限。五分钟后、重新打开拍卖行及 `/reload` 离开拍卖师后仍读保存数量；未知数量提示全扫，历史最高值不参与限制。行情变化只提示手动重算；不把本次重载当成数量变化。实际 Forever 返回及实机耗时仍待验证。
9. 烹饪切换纯钓鱼，核对鱼材料独立于 NPC 配料/图纸，逐配方的钓鱼区域与地图能用；HUD 能跟随制作且导入没有鱼。更换模式再返回读取自己的缓存，切页不重新计算。钓鱼升级页选择区域时确认内陆/海岸、技能加成、实际脱钩和涨点情况；这些实机结果仍待验证。
