结构（与分类树同一定式）：
  • 套装节点本身仍可点选 = 全部 27 套汇总视图；带 +/− 展开箭头。
  • 二级 = 系列行：「海加尔峰 T1」「Forever 专属」，一行一个系列（微底、字重加粗），点行展开/收起。
  • 三级 = 套行：职业色圆点 + 职业色名，右侧件数；点选后右页列出该套全部部件。
  • 徽标计数：套装节点显示「27 套」，系列显示「N 套」，套行显示件数。
  • 未揭示的专属套：灰字 + 「未揭示」小标，可点开看已掉落部件。
  • 复用现有 BuildCats / WalkNode 行池 + 滚动剔除 + 折叠显式 Hide 定式，不另造滚动。
