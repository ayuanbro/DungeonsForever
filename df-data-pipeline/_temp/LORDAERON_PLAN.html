三、boss 攻略该放哪（三个落点方案）

方案 A · 挂进「掉落」页的 boss 分组 改动最小

每个 boss 的组头下面加一行灰色小字。数据加在 Data_DungeonLoot 的 boss 元组上（现 5 个位置：名字EN/名字CN/等级标签/npcID/掉落）。

  • 不动页签结构 → 不碰 SwitchSub、不动 harness / 变异锚
  • 空间小：每 boss 约 1 行，180 字以内
  • 小怪提示与副本须知挤不进去

方案 B · 详情页新增「攻略」子页签 改动最大

与「掉落 / 任务」并列第三个页签，装得下 boss 打法 + 小怪 + 须知 + 提醒。

  • 要动 SwitchSub / 建页 / 池（参考社团页那批改法）
  • harness 断言 + 变异锚要跟着补（按「加断言三件事」）
  • 字号只能 11 / 14 / 16，行宽有硬约束

方案 C · 先只落数据、不做界面

把攻略文本放进新数据文件（如 Data_DungeonTips.lua），界面留到确定版式后再接。好处是内容先固化、不被遗忘；坏处是玩家暂时看不见。
