二、① 子页签行修复（沿用，未变）

文字页签行要在「输出循环 / 宏命令」下不出现。根因已定位：TT.HideSpecContent() 只收 scCards / rowPool / chipPool，没收 secTabs；页签只有 RenderSpec → PaintSecTabs 负责显示，没人负责收 ⇒ 切模式后残留在 y=116~140，正好被宏命令内容的第一行压住（你截图那团重影）。 修法：把 secTabs 收起并进 HideSpecContent()。

五、要补的数据字段

字段含义
name改成无前缀中文名（攻击 / 开怪 / 宠物 / 假死）
