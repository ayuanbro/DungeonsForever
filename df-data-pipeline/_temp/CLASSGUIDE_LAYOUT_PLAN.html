四、三种模式的版面

模式 A · 文字攻略（默认）

正文渲染逻辑（sections / 法术链接 / 种族芯片）完全复用现有实现；只是页签层级变了。

模式 B · 输出循环（新功能，参考 ForeverLevelingGuide「Rotación」）

自上而下 = 优先级；已有 = 绿、稍后 = 金（带解锁等级）；点已有技能 = 拣起放进动作条（PickupSpell）。法术名运行期问客户端，中/英客户端自动跟随。此模式下「文字攻略」子页签行隐藏。

模式 C · 宏命令（新功能，参考 ForeverLevelingGuide「Macros」）

绿 = 现在就能用（点一下写入宏列表，已创建过的会随你学会更强法术自动更新）；金/橙 = 还差前置技能，点击给出学习途径并可在世界地图标出训练师。

五、功能方案（对齐 ForeverLevelingGuide 的行为）
