P2 · 行卡 hover 未走状态机、paint 不复位 §4 静默杀手级

  • :504-532 PaintRow 只切选中描边（:526 SetOutline(r, CG.sel == rec, …)），不切 hover 胶囊；悬停只在 :1140-1153 的 OnEnter / OnLeave 里 Show / Hide。
  • 违反 §4：「paint / OnEnter / OnLeave 三处都要切态，列表路 paint 必须有 norm 恢复分支，防 flat 态回流」。

  • 改法 ②（推荐，与五人本同构）：行池迁到 HuiCardFX(r, 12, 2) + HuiCardState(r, "norm"/"hover") —— 自动拿到 L2 底 + L4 悬停（正好等于本轮手工改出来的值），改造面 ≈ 3 处（底 / 胶囊 / 两处 hover 脚本）。
