改版要点
  • 列序：名称 → 物品等级 → 需要等级 → 类型 → 来源 → 心愿，表头同步换。
  • 来源两行：上行 = 掉落 NPC / 来源性质（boss 名、商人、任务奖励、世界掉落…），下行 = 掉落地点（副本名或地图·子区）。上行 12px 亮色、下行 11px 灰色。
  • 行高 34 → 44：容纳两行来源；每页行数按新行高自动重算（实测页高 ÷ 44）。
  • 心愿列：星标从「悬停才现身」改为常驻最右列，有收藏金色实心 ★、未收藏灰色空心 ☆，直接点击收藏/取消；表头「心愿」。
  • 名称列：保留图标 + 品质色名 + 新增小卡；副行新增「拾取绑定」等说明灰字（可选）。
  • 类型列：部位 · 子类合并一格（如「布甲 · 头部」「拳套」）。
  • 物品等级/需要等级数字按品质淡色，无需求显示「—」。
  • tooltip、Shift+链接、右键收藏、跳副本等交互全部不变。
