二、方案 A（推荐）· 整页卡片流

三张宠物卡竖向排布，每张卡自带「图标 / 名称 / 阵营 + 难度标签 / 来源 + 坐标 / 编号步骤」。一屏看全，不用点选，最贴合现在「睡袋」「战斗法师」两个子页的信息密度。卡片高 144px，三张加间距 446px，正好落在导航高度内、不出现滚动条。

方案 A：整页卡片流。左栏导航新增「宠物 → 小动物」，右栏三张自足卡片。

三、方案 B · 左列表 + 右详情

复刻副本详情的「选中—看详情」交互：左列三只宠物头像竖排可点选，右侧详情面板给大图标、标签、来源、步骤与关联 ID。好处是以后宠物变多不会撑长页面；代价是三只的时候多点一次，且步骤要滚动才看全。

方案 B：左列表 + 右详情。三只时略空，宠物变多时才划算。
